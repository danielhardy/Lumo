## Assessment

This representative run meets both LUMO-107 numeric targets:

- Warm/ordinary p95 input-to-present: `8.632 ms` ≤ `33 ms` — **met**.
- Release-to-settled p95: `9.139 ms` ≤ `200 ms` — **met**.

The direct benchmark does not drive a `PreviewCoordinator` pointer stream, so dropped/coalesced
values are **not applicable**, not zero. Cold startup, supporting histogram work, exhaustive
controls, alternate source sizes, and the complete matrix remain unrun. The captured trace is kept
at the `/tmp` path above; the value-only results are archived here.
